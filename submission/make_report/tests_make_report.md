# Тесты для проверки скрипта make_report

**Подготовка:**
1. Запустить Flask-приложение (`python -m todo.web`).
2. Сгенерировать тестовый набор задач: `python seed.py 100 --url http://127.0.0.1:5000 --seed 42`.

**Шаги проверки:**
1. Запустить скрипт: `python .qwen/skills/make_report/generate_report.py`.
2. Убедиться, что в директории появился файл `report_skill.xlsx`.
3. Открыть файл и проверить:
   - Количество листов ровно 3.
   - Названия листов: "Сводка", "Просроченные", "Ближайшие".
4. Проверить данные на листе "Сводка":
   - Ячейка B2 содержит `100` (всего задач).
   - Ячейка B3 содержит `36` (выполнено).
   - Ячейка B5 содержит `13` (просрочено).
5. Проверить лист "Просроченные": все задачи в списке имеют дату меньше текущей и не выполнены.
6. Проверить лист "Ближайшие": все задачи в списке имеют дату от сегодня до +7 дней.
7. Сверить цифры в Excel с веб-интерфейсом (http://127.0.0.1:5000) — они должны полностью совпадать.
