# make_report — отчёт в Excel по задачам из API

Генерирует Excel-отчёт по задачам из API `http://127.0.0.1:5000/api/tasks` и сохраняет его в `report_skill.xlsx`.

## Когда использовать
Когда пользователь просит сделать отчёт в Excel по задачам (например, «сделать отчёт в Excel», «сгенерировать xlsx с задачами»). Скрипт сам берёт данные с API, строит три листа и сохраняет файл.

## Инструкция запуска
Скрипт: `.qwen/skills/make_report/generate_report.py` (требуется openpyxl, остальное — стандартная библиотека).

```bash
python .qwen/skills/make_report/generate_report.py
```

Параметры:
- `--url URL` — URL API (по умолчанию `http://127.0.0.1:5000/api/tasks`)
- `--out ПУТЬ` — путь к выходному файлу (по умолчанию `report_skill.xlsx`)

Пример с явными параметрами:

```bash
python .qwen/skills/make_report/generate_report.py \
  --url http://127.0.0.1:5000/api/tasks \
  --out report_skill.xlsx
```

## Что создаётся
Файл `report_skill.xlsx` (в корне проекта, если не указан `--out`) с тремя листами:
- **«Сводка»** — всего задач; выполнено (шт. и %); не выполнено; просрочено; разбивка по приоритетам High/Normal/Low (Всего / Выполнено / %).
- **«Просроченные»** — невыполненные задачи с дедлайном строго меньше текущей даты; колонки ID, Название, Приоритет, Дедлайн; сортировка по дате.
- **«Ближайшие»** — невыполненные задачи с дедлайном от сегодня до +7 дней включительно; колонки ID, Название, Приоритет, Дедлайн; сортировка по дате.

Данные API: JSON-массив объектов `{id, title, priority: "low"|"normal"|"high", done: bool, due: "YYYY-MM-DD" | null}`. Задачи без дедлайна (`due: null`) не попадают ни в «Просроченные», ни в «Ближайшие».

## Проверка результата
После генерации сверить файл с API:
- листов ровно 3 с названиями «Сводка», «Просроченные», «Ближайшие»;
- для текущего набора данных: всего 100 задач, 36 выполнено (36.0%), 13 просрочено;
- строки «Просроченные»/«Ближайшие» совпадают с невыполненными задачами API (даты, приоритеты), отсортированы по дате.
