# Техническое задание на разработку скрипта make_report

**Цель:** Создать Python-скрипт `generate_report.py`, который обращается к REST API TODO-приложения (`/api/tasks`), собирает данные и формирует Excel-отчет.

**Требования к скрипту:**
1. Использовать библиотеку `openpyxl` для работы с Excel.
2. Файл должен сохраняться под именем `report_skill.xlsx`.
3. Отчет должен содержать минимум 3 листа:

**Лист 1: "Сводка"**
- Общее количество задач.
- Количество выполненных задач (шт и %).
- Количество просроченных задач.
- Разбивка по приоритетам (High, Normal, Low): всего задач, выполнено, доля выполнения в %.

**Лист 2: "Просроченные"**
- Колонки: ID, Название, Приоритет, Дедлайн.
- Включает только задачи, у которых дедлайн строго меньше текущей даты И статус "не выполнена".
- Сортировка по возрастанию даты дедлайна.

**Лист 3: "Ближайшие"**
- Колонки: ID, Название, Приоритет, Дедлайн.
- Включает только невыполненные задачи, у которых дедлайн входит в диапазон от сегодняшней даты (включительно) до сегодняшней даты + 7 дней.
- Сортировка по возрастанию даты дедлайна.

**Архитектурные требования:**
- Скрипт должен быть устойчив к отсутствию поля `due` (дедлайн) у задачи.
- Скрипт должен корректно обрабатывать формат даты `YYYY-MM-DD`.
